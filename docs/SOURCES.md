# Catalogue des sources

Ce document complète le registre machine-readable `config/sources.yml`.

## INSEE

Usage prioritaire :

- comptes nationaux ;
- comptes des administrations publiques ;
- prélèvements obligatoires ;
- dépenses par fonction (COFOG) ;
- PIB ;
- population ;
- indices de prix.

Les données INSEE servent de socle pour les agrégats macroéconomiques français.

## Budget de l'État

**budget.gouv.fr**

Usage :

- lois de finances ;
- exécution budgétaire ;
- missions et programmes ;
- documents budgétaires ;
- données ouvertes associées.

Attention : le budget de l'État ne représente qu'une partie de la dépense publique totale.

## data.gouv.fr

Catalogue national de données publiques.

Usage envisagé :

- commande publique ;
- aides et subventions lorsque publiées ;
- données administratives sectorielles ;
- jeux produits par les ministères et opérateurs publics.

Chaque jeu doit être relié à son producteur d'origine.

## Cour des comptes

Usage :

- contrôle de gestion publique ;
- certification ;
- évaluation de politiques publiques ;
- estimations et constats sur les systèmes de contrôle et de fraude.

Une recommandation ou appréciation de la Cour doit être distinguée d'une donnée statistique brute.

## DREES et Sécurité sociale

Usage :

- protection sociale ;
- retraites ;
- santé ;
- famille ;
- minima sociaux ;
- comptes de la protection sociale.

## DGFiP et administrations fiscales

Usage :

- recettes fiscales ;
- fiscalité ;
- données fiscales agrégées ;
- contrôle et fraude fiscale lorsque des données comparables existent.

## Eurostat

Usage :

- séries harmonisées européennes ;
- comparaison avec les autres États membres ;
- validation croisée de certains agrégats français.

## OCDE

Usage :

- comparaisons internationales ;
- prélèvements ;
- dépenses ;
- emploi public ;
- indicateurs sectoriels harmonisés.

## Commission européenne

Usage :

- aides d'État ;
- règles et bases européennes associées ;
- données permettant des comparaisons européennes.

## Règle de citation

Chaque analyse doit citer le producteur original et conserver suffisamment d'informations pour retrouver précisément le jeu de données ou le document utilisé.
