# Contribuer

Toute contribution est bienvenue si elle respecte les principes de reproductibilité et de neutralité méthodologique du projet.

## Pour une nouvelle analyse

Avant d'ajouter une conclusion :

1. formuler la question et les hypothèses ;
2. identifier les sources primaires ;
3. documenter les définitions et périmètres ;
4. automatiser autant que possible l'acquisition et le traitement ;
5. vérifier les unités et les ruptures de série ;
6. tester des métriques alternatives pertinentes ;
7. documenter les limites ;
8. fournir les commandes de reproduction.

Les opinions politiques ne constituent ni une source ni une méthode de validation.

## Code

- Python >= 3.11 ;
- format et lint avec Ruff ;
- tests avec pytest ;
- pas de modification manuelle des données brutes.


## Licence des contributions

En proposant une contribution, vous confirmez disposer des droits nécessaires pour la soumettre au projet.

- les contributions de **code** sont proposées sous `AGPL-3.0-or-later` ;
- les contributions de **documentation, texte d'analyse ou contenu éditorial original** sont proposées sous `CC-BY-4.0` ;
- les données ou contenus provenant de tiers doivent conserver leur licence d'origine et être accompagnés d'une attribution et d'une provenance suffisantes.

Une contribution ne doit pas introduire de contenu dont la licence est incompatible avec le périmètre concerné.
