# Analyses

Chaque sous-dossier représente une analyse autonome et reproductible.

Structure recommandée :

```text
analyses/<theme>/
├── README.md
├── analysis.py
├── figures/
└── tables/
```

Le README de chaque analyse doit contenir : question, hypothèses, sources, méthode, résultats, limites et commande de reproduction.

Premiers thèmes envisagés :

- `macro/` : finances publiques agrégées 2000–2025 ;
- `taxation/` : prélèvements obligatoires ;
- `education/` ;
- `health/` ;
- `security_justice/` ;
- `social_protection/` ;
- `fraud/` ;
- `corporate_aid/` ;
- `debt/`.
