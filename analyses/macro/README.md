# Analyse macro 2000–2025

Cette analyse constitue le premier socle du projet.

## Question

Comment les principales grandeurs des finances publiques françaises ont-elles évolué entre 2000 et 2025 ?

## Variables cibles

- PIB ;
- population ;
- inflation / indice de prix ;
- dépenses publiques ;
- recettes publiques ;
- prélèvements obligatoires ;
- solde public ;
- dette publique ;
- intérêts versés.

## Vues à produire

Pour toute grandeur monétaire pertinente :

1. euros courants ;
2. euros constants avec année de référence explicitée ;
3. euros par habitant ;
4. part du PIB.

## Contrôles

- cohérence des unités ;
- couverture 2000–2025 ;
- détection des valeurs manquantes ;
- documentation des changements de base statistique ;
- contrôle croisé ponctuel avec Eurostat ;
- vérification des agrégats consolidés pour éviter les doubles comptes.
