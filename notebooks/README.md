# Notebooks

Les notebooks servent à l'exploration, à la visualisation et aux contrôles ponctuels.

Les traitements nécessaires à la reproductibilité d'un résultat final doivent être déplacés dans `src/acfpf/`, `scripts/` ou dans le dossier d'analyse concerné.

Un résultat important ne doit pas dépendre d'un état caché d'un notebook.
